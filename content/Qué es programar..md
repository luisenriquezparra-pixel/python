**Programar** es el proceso de crear un conjunto de instrucciones precisas y ordenadas ([[un algoritmo]]) que indica a una [[computadora]] como realizar tareas, automatizar procesos o solucionar problemas, consiste en explicarle a una computadora los pasos que tiene que realizar para resolver un problema.

**¿Porque existe?** La programación surgió gracias a la necesidad del ser humano por automatizar procesos, con el fin de facilitarnos la vida.

**¿Para que sirve?** Sirve para crear software, automatizar procesos y resolver problemas.

**¿Qué problema resuelve?** La programación no solo resuelve "tareas" o "[[automatiza procesos]]"; su propósito principal es gestionar ideas caóticas ambiguas y complejas, para convertirlo en instrucciones lógicas, ordenadas, estructuradas y ejecutables para una maquina.

**¿Como funciona?** El programador escribe código usando un lenguaje como Python. el lenguaje interpreta el codigo, lo transforma en instrucciones para la maquina, la cpu ejecuta esas instrucciones y el programa produce resultados
