## 📚 Áreas de aprendizaje

---

### 🧮 Matemática / Sistemas numéricos

#### 🔹 [[binarios]]

Sistema base 2 usado por las computadoras.

📌 **Idea clave:**  
Solo usa `0` y `1`

📊 **Ejemplo:**

```
101 = 5 en decimal
```

🧠 **Para qué sirve:**

- Representar datos en la computadora
    
- Entender cómo funciona el hardware
    

---

#### 🔹 [[hexagesimal]]

Sistema base 16 (más compacto que binario)

📌 **Idea clave:**  
Usa:

```
0–9 y A–F
```

📊 **Ejemplo:**

```
A = 10
F = 15
```

🧠 **Para qué sirve:**

- Colores en programación (#FF0000)
    
- Memoria y direcciones
    

---

### 💻 Programación

#### 🔹 [[if]]

Condicional que toma decisiones en el código

📌 **Estructura básica:**

```python
if condicion:
    accion
```

📊 **Ejemplo:**

```python
if 5 > 3:
    print("verdadero")
```

🧠 **Para qué sirve:**

- Controlar el flujo del programa
    
- Crear lógica (decisiones)
